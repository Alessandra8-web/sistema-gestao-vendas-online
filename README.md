# Sistema de Gestão de Vendas Online

Projeto Front-End desenvolvido para um Sistema de Gestão de Vendas Online voltado para a comercialização de caixinhas de som.

O sistema tem como objetivo auxiliar no gerenciamento de vendas, permitindo o acesso ao painel principal, registro de pedidos e acompanhamento de relatórios de vendas.

## Tecnologias Front-End

Para o desenvolvimento da interface foram utilizadas as seguintes tecnologias:

- HTML5: estruturação das páginas da aplicação;
- CSS3: estilização, organização visual e responsividade;
- JavaScript: implementação das interações e funcionalidades dinâmicas.

## Funcionalidades implementadas

Durante a primeira Sprint foram implementadas quatro tarefas principais:

### 1. Tela de Login

Interface inicial do sistema contendo:

- Campo de e-mail;
- Campo de senha;
- Botão Entrar;
- Opção "Esqueci minha senha";
- Navegação para o Dashboard.

### 2. Tela de Dashboard

Painel principal do sistema contendo:

- Resumo dos pedidos realizados;
- Pagamentos confirmados;
- Total de vendas;
- Visualização dos últimos pedidos;
- Situação dos pagamentos;
- Gráfico demonstrativo de vendas;
- Menu de navegação.

### 3. Tela de Pedidos

Interface destinada ao registro de novos pedidos contendo:

- Seleção de cliente;
- Seleção do produto;
- Quantidade;
- Cálculo automático do valor total;
- Seleção da forma de pagamento;
- Registro do pedido.

### 4. Tela de Relatórios

Interface para acompanhamento das vendas contendo:

- Total de pedidos;
- Quantidade de vendas confirmadas;
- Faturamento;
- Relação de pedidos;
- Clientes;
- Produtos;
- Valores;
- Situação dos pagamentos;
- Opção para emitir relatório.

## Organização do projeto

O projeto está organizado nos seguintes arquivos:

- `index.html` - Tela de Login;
- `dashboard.html` - Tela de Dashboard;
- `pedido.html` - Tela de Pedidos;
- `relatorios.html` - Tela de Relatórios;
- `README.md` - Documentação do projeto.

## Versionamento

O projeto foi versionado utilizando Git e GitHub.

As funcionalidades foram registradas por meio de commits durante o desenvolvimento, permitindo acompanhar a evolução e a implementação das tarefas da Sprint.
